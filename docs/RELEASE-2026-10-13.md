## Release Fixes

- Treatment routes invoke the Worker before static assets; missing D1 prices fail visibly. Static
  template cache validators are removed so database edits cannot return a stale 304 response.
- Reopening admin retains unpublished treatment drafts. Both treatment editors and publishing omit
  percentage-off badges while retaining other highlights.
- Stale scheduled sends become errors requiring provider-log review, rather than being resent.
  The admin exposes cancellation for failed or stale sends.
- Birthday sends persist successful batches immediately. Durable claims prevent overlapping sends
  and hold uncertain deliveries after a network failure or server error. Definite non-timeout client
  rejections release the claim so a later run may retry. Pending cases appear in dashboard alerts.
- Subscriber erasure uses an atomic D1 batch. A durable cleanup job allows suppression KV deletion
  to resume after an outage, before the next cron sends mail. Audit history is retained.
- Multipart and URL-encoded RFC 8058 unsubscribe POSTs work; GET requires confirmation.
- Updated JavaScript cache versions and fixed test-fixture lint errors.
- Earlier JWT validation, missing-secret rejection, consent-history append, preference fail-closed,
  media-upload protection, asset cleanup and frontend fixes remain included.
